# Week 0 kit

Kickoff session for the AI/ML/Optimization track: **"Belajar AI lewat paper"** (120 minutes, separate from the 16 teaching weeks). The session shows four kinds of papers (pure research, applied, a field that keeps improving, paper to poster) with real papers from our campus, teaches how to read one in 10 minutes, and ends with setup.

| Folder | For | What |
|---|---|---|
| `slides/` | Mentors (projector) | The kickoff deck on the lab's PowerPoint template (28 slides, speaker notes) and a PDF backup |
| `site/` | Students (deployed) | Participant handout and the "Evolusi Gambar" demo |
| `notebooks/` | Students (Colab) | Python for Go programmers (pre-work), Optimizer 20 baris (Week 1 opener) |
| `fasilitator/` | Mentors only | Run sheet and answer keys, printable pretest, printable detective cards, answer-key notebooks |

Start with `fasilitator/panduan-fasilitator.md`. Section 13 lists what must be confirmed before the links go to students. Deploy steps are in `../docs/deploy-netlify.md`.
