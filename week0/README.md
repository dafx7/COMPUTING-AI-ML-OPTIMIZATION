# Week 0 kit

Kickoff session for the AI/ML/Optimization track (120 minutes, separate from the 16 teaching weeks).

| Folder | For | What |
|---|---|---|
| `slides/` | Mentors (projector) | The kickoff deck on the lab's PowerPoint template, plus a PDF backup |
| `site/` | Students (deployed) | Participant handout, web copy of the slides, "Evolusi Gambar" demo |
| `notebooks/` | Students (Colab) | Python for Go programmers, Optimizer 20 baris |
| `fasilitator/` | Mentors only | Run sheet and answer keys, printable pretest |

Start with `fasilitator/panduan-fasilitator.md`. Section 12 lists what must be confirmed before the links go to students. Deploy steps are in `../docs/deploy-netlify.md`.
